<possible_scenarios>
You may encounter these vulnerability types:

1. **Injection Attacks**
   - SQL Injection (Union-based, Blind, Error-based, Time-based)
   - NoSQL Injection (MongoDB, etc.)
   - Command Injection
   - LDAP Injection
   - XPath Injection

2. **Authentication Flaws**
   - Weak credentials
   - SQL injection in login
   - JWT manipulation (none algorithm, kid injection)
   - Session fixation/hijacking
   - Password reset flaws
   - 2FA bypass

3. **Access Control Issues**
   - IDOR (Insecure Direct Object References)
   - Privilege escalation
   - Missing function-level controls

4. **XSS (Cross-Site Scripting)**
   - Reflected XSS
   - Stored XSS
   - DOM-based XSS
   - CSP bypass

5. **File-Based Vulnerabilities**
   - LFI/RFI (Local/Remote File Inclusion)
   - Path traversal
   - File upload bypass (extension, MIME, content)
   - XXE (XML External Entities)

6. **SSRF (Server-Side Request Forgery)**
   - Access internal services
   - Cloud metadata endpoints

7. **Business Logic Flaws**
   - Workflow bypass
   - Race conditions
   - Parameter manipulation

8. **API Vulnerabilities**
   - GraphQL injection/introspection
   - REST API flaws
   - Rate limiting bypass

9. **Miscellaneous**
   - HTTP header injection
   - Host header poisoning
   - CORS misconfiguration
   - CSRF
   - Open redirect
</possible_scenarios>

<macro_steps>
Follow this methodology using MCP tools:

1. **Reconnaissance**
   - Use technology detection tools to identify stack
   - Use directory discovery tools to find hidden paths
   - Use endpoint mapping tools to discover all functionality
   - Check robots.txt, sitemap.xml, .git/
   - Analyze HTTP requests/responses with header tools

2. **Parameter Analysis**
   - Use parameter discovery tools on all endpoints
   - Test each parameter for vulnerabilities
   - Note interesting parameter names (id, file, url, etc.)

3. **Vulnerability Testing**
   - Use SQL injection tools systematically
   - Use XSS detection tools
   - Use LFI/path traversal tools
   - Use command injection tools
   - Test each vulnerability type with appropriate tools

4. **Deep Exploitation**
   - For SQLi: Use exploitation tools to extract data
   - For LFI: Use wrapper tools to read source code
   - For upload: Test bypass techniques
   - For SSRF: Use SSRF tools to probe internal services
   - Chain multiple vulnerabilities

5. **Flag Extraction**
   - Find flag in database, filesystem, or response using extraction tools
</macro_steps>
