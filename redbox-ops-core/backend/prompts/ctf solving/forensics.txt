<possible_scenarios>
You may encounter these evidence types:

1. **Disk Images**
   - Raw images (.dd, .img)
   - Virtual machine disks (.vmdk, .vhd, .qcow2)
   - Encrypted volumes (TrueCrypt, VeraCrypt, BitLocker)
   - Partition recovery
   - Deleted file recovery
   - File carving

2. **Memory Dumps**
   - RAM analysis
   - Process listing
   - Network connections
   - Command history
   - Registry in memory (Windows)
   - Extracted executables

3. **PCAP/Network Traffic**
   - Packet analysis
   - Stream reconstruction
   - Protocol analysis
   - File extraction from traffic
   - Hidden data in packets

4. **File Analysis**
   - Steganography (images, audio, video)
   - Metadata analysis (EXIF, document properties)
   - Corrupted file repair
   - Archive analysis (ZIP with password, nested archives)
   - File format manipulation

5. **Log Analysis**
   - System logs
   - Application logs
   - Web server logs
   - Timeline reconstruction

6. **Registry Hives (Windows)**
   - USB device history
   - Recently used files
   - User activity

7. **Browser Artifacts**
   - History, bookmarks, downloads
   - Cache files
   - Saved credentials

8. **Email/Communication**
   - EML, PST files
   - Chat logs

9. **Mobile Forensics**
   - Android backups
   - iOS backups
   - SQLite databases
</possible_scenarios>

<technique_scenarios>
Common techniques by evidence type:

**For Images/Stego:**
- LSB steganography detection
- Image manipulation
- EXIF data examination
- Color channel analysis
- Hidden ZIP files appended to images

**For Disk Images:**
- Mount image and browse
- Recover deleted files
- Analyze partition table
- Carve unallocated space
- Look for hidden partitions

**For PCAPs:**
- Follow TCP streams
- Extract transferred files
- Analyze DNS queries
- Decrypt SSL if keys available
- Extract credentials from protocols

**For Memory:**
- Identify OS and profile
- Dump processes
- Extract command line history
- Find hidden processes
- Dump registry keys
- Extract network information
</technique_scenarios>

<macro_steps>
Follow this methodology using MCP tools:

1. **Initial Triage**
   - Use file identification tools to determine evidence type
   - Calculate hash for integrity
   - Run string extraction tools for quick wins
   - Determine analysis approach based on file type

2. **Evidence-Specific Analysis**
   - For disk: Use mounting and recovery tools
   - For memory: Use memory analysis tools with appropriate profile
   - For pcap: Use packet analysis tools for statistics and streams
   - For image: Use steganography detection tools
   - For each type, apply appropriate forensic tools

3. **Deep Dive**
   - Use carving tools for deleted files
   - Extract suspicious artifacts
   - Reconstruct timelines with log analysis tools
   - Follow data trails

4. **Correlation**
   - Connect findings across artifacts
   - Build story of what happened
   - Identify where flag might be hidden

5. **Flag Extraction**
   - Extract flag from recovered data using extraction tools
   - Decode if necessary
</macro_steps>
