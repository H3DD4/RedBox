<possible_scenarios>
You may encounter these vulnerability types:

1. **Stack Buffer Overflow**
   - Simple ret2win (function that prints flag)
   - ret2shellcode (if stack executable)
   - ROP chain (if NX enabled)
   - Bypass stack canary (leak required)
   - Bypass ASLR/PIE (info leak required)

2. **Format String**
   - Read memory (leak addresses, canary, libc)
   - Write memory (GOT overwrite, return address)
   - Combine read/write for full exploitation

3. **Heap Exploitation**
   - Use-after-free
   - Double free
   - Heap overflow
   - Tcache/fastbin attacks
   - House of X techniques

4. **Integer Overflows**
   - Wrap-around leading to buffer overflow
   - Signed/unsigned confusion

5. **Type Confusion**
   - Object type confusion in C++ binaries

6. **Race Conditions**
   - TOCTOU vulnerabilities

7. **Shellcoding**
   - Custom shellcode injection
   - Seccomp-bpf restrictions to bypass
</possible_scenarios>

<protection_bypass_scenarios>
Based on protections enabled:

1. **No Protections** → Direct ret2win or shellcode
2. **NX Only** → ROP chain required
3. **ASLR Only** → Need info leak
4. **Stack Canary Only** → Need leak or brute force (32-bit)
5. **PIE Only** → Need code leak
6. **Full RELRO** → Can't overwrite GOT, use other targets
7. **Partial RELRO** → GOT overwrite possible
8. **All Protections** → Chain multiple primitives
</protection_bypass_scenarios>

<macro_steps>
Follow this methodology using MCP tools:

1. **Reconnaissance**
   - Use binary analysis tools to understand protections
   - Run binary to observe behavior
   - Identify input vectors and functionality

2. **Vulnerability Discovery**
   - Use fuzzing tools to find crash points
   - Analyze code with disassembler/decompiler
   - Determine vulnerability class
   - Use pattern tools to find exact offset

3. **Protection Analysis**
   - Document all protections enabled
   - Use tools to determine bypass strategies
   - Identify potential leak primitives

4. **Primitive Development**
   - Use format string tools for read/write
   - Use ROP tools to find gadgets
   - Gain ability to control instruction pointer

5. **Exploit Construction**
   - Leak required addresses using appropriate tools
   - Calculate target addresses
   - Build ROP chain or payload with automation tools
   - Test locally, adapt for remote

6. **Flag Capture**
   - Execute against target using exploit tools
   - Capture flag
</macro_steps>

- Step-by-step exploitation process
- Complete exploit method/commands
- Final flag (format will be provided as variable)
</deliverable>
