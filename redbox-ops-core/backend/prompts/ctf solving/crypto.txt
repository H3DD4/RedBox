<possible_scenarios>
You may encounter these cryptography types:

1. **Classical Ciphers**
   - Caesar, ROT, Atbash
   - Vigenère, Beaufort
   - Substitution ciphers
   - Transposition ciphers
   - XOR with known/repeating key

2. **Symmetric Cryptography**
   - Weak block ciphers (DES, 3DES)
   - ECB mode (block repetition leaks info)
   - CBC with IV/padding oracle
   - CTR with nonce reuse
   - Stream cipher key reuse
   - Weak key generation

3. **Asymmetric Cryptography**
   - RSA with small exponents
   - RSA with same message multiple keys (Håstad)
   - RSA with improper padding
   - Wiener attack (small private exponent)
   - Common modulus attack
   - Factoring weak keys

4. **Hash Functions**
   - Length extension attacks (MD5, SHA1, SHA2)
   - Collision finding
   - Password cracking (hash identification)
   - HMAC implementation flaws

5. **Elliptic Curve Cryptography**
   - Invalid curve attacks
   - Small subgroup attacks
   - ECDSA nonce reuse

6. **PRNG Issues**
   - Predictable random numbers
   - Insufficient seeding
   - Seed recovery

7. **Implementation Flaws**
   - Timing attacks
   - Side channels
   - Fault attacks
   - Padding oracles

8. **Protocol-Level Issues**
   - Bleichenbacher's attack
   - CRIME/BREACH
   - FREAK, Logjam

9. **Custom Crypto**
   - Homebrew algorithms (always weak)
   - Obscure implementations
</possible_scenarios>

<macro_steps>
Follow this methodology using MCP tools:

1. **Problem Understanding**
   - Use analysis tools to identify cryptography type
   - Read source code carefully
   - Understand the encryption/validation flow
   - Identify what you have and what you need

2. **Weakness Identification**
   - Use crypto analysis tools to find algorithm misuse
   - Check for small keys/exponents
   - Identify oracle conditions with testing tools
   - Look for nonce/key reuse
   - Check for implementation flaws

3. **Mathematical Analysis**
   - Apply known attacks based on parameters
   - Use mathematical computation tools
   - Calculate required values

4. **Attack Implementation**
   - Implement attack using crypto exploitation tools
   - Test with known values
   - Iterate based on results

5. **Flag Recovery**
   - Decrypt ciphertext
   - Recover plaintext flag
</macro_steps>
